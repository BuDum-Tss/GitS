# Контур.Толк

Чтобы подключить ГЛаДОС, передайте ссылку на комнату `https://пространство.ktalk.ru/комната`
в диалоге или в панели «Контур.Толк». В комнате должен быть разрешён гостевой вход.
Окружение показывает ожидание допуска и закрывает браузер при отключении.

Отдельный Chromium подключается гостем. Каждая входящая WebRTC-дорожка,
которую Толк обозначает `remote-audio-N`, получает собственный PCM-поток в
голосовом движке. Имя дорожки берётся со страницы: если в комнате один
удалённый участник и одна дорожка, подпись берётся из его плитки; если участников
несколько, имя находит совпадение звука дорожки с подсветкой говорящей плитки
(класс `active-speaker`), после нескольких совпадений подпись обновляется. Пока имя
не найдено, источник называется «Участник 1», «Участник 2» и т. д. (номер относится
к дорожке в текущем звонке). Ответы идут через виртуальный
микрофон PulseAudio. Адаптер не сохраняет аудио на диск.

Для запуска пересоберите образ ядра. Он использует те же Chromium, Playwright
и PulseAudio, что и окружение Телемоста. Ключ API Толка для гостевого входа не
требуется. Доступ к закрытым комнатам пока не реализован. Сопоставление имён при нескольких
одновременных участниках проверено только по структуре страницы с одним удалённым
участником.
