# GitS: ГЛаДОС, ассистентка на компьютере

Всегда включённый ассистент с характером из папки персонажа (сейчас ГЛаДОС): разговор, зрение (экран), голос и слух, управление
компьютером, память-граф, собственные размышления и напоминания, Telegram, игры, питомец на рабочем столе. Всё на Python 3.12+,
ввод-вывод асинхронный (`asyncio`). Локальная модель (LM Studio) отвечает за быстрые реплики и разбор намерений, Claude Code SDK
берёт тяжёлые задачи. Она не болтает по таймеру: говорит в ответ на события, на просьбы и на напоминания, которые назначила себе.

## Как это устроено

**Ядро** (`agent/`) принимает события от источников, решает, что с ними делать, говорит и помнит. **Модули** (`modules/`) это
отдельные процессы, которые подключаются к ядру по WebSocket (`ws://127.0.0.1:8766/module/ws`) и общаются только по
контракту; ядро само запускает их по `agent/modules.yaml`.

Ядро разрезано на слои (ТЗ 29, чистая архитектура):

| Слой | Где | Что внутри |
|---|---|---|
| Домен | `agent/domain/` | чистые функции решений без ввода-вывода: приоритет и свежесть, правила («замолчи», «похоже на просьбу»), риск, политика фокуса, лимиты импульсов, `Event` |
| Сценарии | `agent/app/` | нормализация события, оценка, диспетчер (маршруты `say`, `chat`, `task`, `focus`, `think`, `digest`), разговор, контекст, ответ, запоминание, размышление, таймер импульсов |
| Адаптеры | `agent/adapters/` | локальная модель, SQLite-журнал, личная память, люди, настройки, разрешения, файлы напоминаний и мыслей |
| Контракты | `agent/contracts.py` | интерфейсы между сценариями и адаптерами (`LanguageModel`, `MemoryReader`, `MemoryWriter`, `PeopleDirectory`, `EventLog`, ...) |
| Корень сборки | `agent/core_service.py`, `agent/main.py` | собирает всё вместе, запускает слои |

Путь события: источник (модуль или чат дашборда) -> шина модулей (`module_hub.py`) -> менеджер внимания (`attention.py`: правила,
классификатор GLiNER, приоритет, решение D0-D4, маршруты) -> разговор / планировщик инструментов (`router.py`) / менеджер фокуса
(`focus.py`) / сводка / размышление (`app/reflection.py`). Речь идёт только через очередь речи внимания (`speech_queue.py`) и не
при «не отвлекать». Внутренние импульсы: сама назначенная отметка («напомни себе через час», план пользователя со сроком, разговор
затих) становится событием `self.*` и попадает в то же размышление; мысли пишутся в журнал и не озвучиваются.

Память: личная (`memory_store.py`, `user_memory.py`: факты, планы, эпизоды), граф фактов (Graphiti + FalkorDB, `graph_memory.py`),
гибридный поиск (`agent/search/`), воспоминания персонажа о себе. Эмоции (ТЗ 26) и настроение влияют на тон.

Схему архитектуры (группы, компоненты, связи, статусы «есть/планируется») показывает вкладка **«Схема»** дашборда
(`http://localhost:8766`). Источник схемы: `agent/tools/architecture/spec.py`, сборка: `cd agent && python -m tools.architecture.build`
(тест `agent/tests/test_architecture_spec.py` следит, чтобы собранное совпадало с источником).

## Модули

| Модуль | Папка | Что делает |
|---|---|---|
| Голос | `modules/voice` | микрофон и распознавание (WhisperX, запасной faster-whisper), узнавание голосов, синтез (Fish Speech, запасной edge-tts), воспроизведение, слух системного звука |
| Питомец | `modules/pet` | окно на рабочем столе: стикер и облачко по состоянию (`presence`) |
| Компьютер | `modules/desktop` | зрение и экран, мышь и клавиатура, приложения, Claude-помощник как задача |
| Telegram | `modules/telegram` | канал-дневник, бот, её собственный аккаунт |
| RimWorld | `modules/rimworld` | мод, MCP-сервер, игровые контуры на Claude, комментатор |
| Монтаж | `modules/montage` | конвейер роликов (Remotion, ffmpeg, агент Claude) |

Включаются во вкладке «Модули» дашборда (там же настройки, задачи и вопросы модулей). Профили поведения: `agent/profiles/*.yaml`.
Игровые и прочие специальные вещи живут только в своём модуле, в ядре их нет.

### Контракты и новый модуль
- **Контракт «ядро - модуль»** описан в одном месте, `sdk/gits_sdk/contract/` (запросы, сообщения, темы, окружение, версии). Из него
  скриптом `python sdk/tools/gen_contract_doc.py` строятся [docs/MODULE_CONTRACT.md](docs/MODULE_CONTRACT.md) и схемы `docs/contract/*.json`
  (тест сверяет). Запросы модуля к ядру: `core.ask`, `core.tts`, `core.tool.call`, `core.persona`, `core.llm.ask`,
  `core.memory.recall` / `core.memory.remember` и другие; запросы справочника (`core.lookup`, `core.experience.add`, `core.kb.ingest`)
  работают (ТЗ 04, контракт 1.4); справочники грузит `agent/tools/knowledge_ingest.py`.
- **SDK** (`sdk/`, пакет `gits-sdk`): типизированный `ModuleClient`, `FakeCore` для тестов без ядра. Ядро берёт SDK напрямую из репозитория
  (`agent/main.py` добавляет `sdk` в `sys.path`), ставить его не нужно; для модуля в своём окружении: `pip install -e sdk`.
- **Шаблон нового модуля**: [sdk/template/](sdk/template/README.md) (манифест, обработчики, точка входа, тесты на `FakeCore`);
  пример с задачей, прогрессом и вопросом пользователю: `sdk/examples/echo_module.py` (выключен по умолчанию).
  Руководство автора: [docs/MODULES.md](docs/MODULES.md). Модули не импортируют файлы `agent/` (тест это ловит).

## Запуск
```powershell
cd agent
pip install -r requirements.txt -r ../modules/voice/requirements.txt    # ядро и звук
copy secrets.env.example secrets.env     # токены Telegram и т.д. (не в git)
python main.py                           # ядро и дашборд на http://localhost:8766; модули запускает само ядро
pythonw tray.py                          # трей: поднимает только ядро
```
- Внешние сервисы (необязательные): `docker compose up -d` поднимает граф памяти (FalkorDB), Fish Speech и WhisperX. Локальная модель:
  LM Studio (`google/gemma-4-e4b` и эмбеддинги EmbeddingGemma). Классификатор внимания GLiNER: `services/decider/README.md`.
- Без Fish Speech модуль голоса говорит запасным edge-tts (нужен интернет); без WhisperX микрофон распознаёт локально (faster-whisper,
  веса скачивает владелец сам). Если голос выключен, она отвечает текстом в чате дашборда.
- Без звука и без окна для проверки запуска: `GITS_VOICE_FAKE=1`, `GITS_PET_HEADLESS=1`. Выключить второй эшелон фокуса: `GITS_FOCUS_LLM=0`.
- Вручную (при разработке, ядро должно работать): `python modules/voice/main.py`, `python modules/pet/main.py`.
- Telegram: токен бота и канал (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL`) и ключи аккаунта (`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`) лежат
  в `agent/secrets.env`; вход в аккаунт один раз вручную: `python modules/telegram/tg_login.py`.

### Дашборд
Вкладки: **Состояние** (профили, внимание, фокус, эмоции, задержка реплики и бюджеты задержек), **Память** (что помнит, граф, эпизоды),
**Мысли** (журнал размышлений и напоминания себе), **Модули** (карточки, настройки, задачи, вопросы, пространство модуля),
**События** (протокол), **Схема** (архитектура), **Настройки**.

## Персонажи
Персонаж (ГЛаДОС сейчас) это данные, а не код: папка `resources/<Имя>/` с `character.yaml` (карточка), `core/` (промпты и воспоминания ядра)
и по папке на модуль (`voice/`, `pet/`, `telegram/`, `desktop/`, `rimworld/`, `montage/`). Модуль берёт ресурсы только из своей папки
(`gits_sdk.resources.module_dir("pet")`). Память у каждого персонажа своя (`memory/` для `glados`, `memory/characters/<id>/` для остальных).

Как добавить персонажа:
1. Скопировать `resources/_template/` в `resources/<Имя>/` (id в `character.yaml`: строчные латинские буквы, цифры, `_`).
2. Заполнить `character.yaml`: `id`, `name`, `aliases`, `anchor` (до 600 символов), `voice`.
3. Написать `core/prompt.yaml` и `<модуль>/persona.yaml`. `core/constitution.yaml` меняет только человек.
4. Воспоминания: `core/memories.yaml`, загрузка в граф `python -m character seed <id>` (`--dry-run` только проверяет файл).
5. Переключение: дашборд (`POST /api/character`) или инструмент `core.set_character`.

## Характер, память и учёба
Эмоции (валентность, возбуждение, настроение с затуханием к базовому уровню персонажа), эпизоды с резюме от первого лица и режим сна с дневником (`memory/episodes.db`), уроки на ошибках и убеждения, которые она принимает сама с журналом изменений и отменой в дашборде (ТЗ 26-28). Поиск по памяти гибридный (`agent/search/`: слова и векторы). Конституция меняется только человеком.

## Быстрый контур
Реплика идёт по понятным маршрутам (`reflex`, `chat`, `task`, `ignore`, `think`, [docs/ROUTES.md](docs/ROUTES.md)): жёсткие правила
до моделей («замолчи» и другое, `agent/routes/hard_rules.yaml`), затем параллельно классификатор, приказ в игру и поиск в памяти
(дедлайн 300 мс). Ответ локальной модели идёт потоком: первое предложение звучит, пока остальные ещё генерируются; «замолчи» и
перебивание обрывают генерацию. На поручении она быстро подтверждает, что взялась. Настройки `fast_contour` и `latency_budget`;
сравнение до и после на заглушках: `python agent/tools/measure_e2e.py --compare`.

## Устойчивость ядра
`python agent/tools/soak_core.py --minutes 10` поднимает настоящее ядро без модулей (модель и речь заглушены), шлёт реплики и события,
подключает и роняет фиктивные модули и раз в 10 секунд снимает память, задержку цикла событий, число задач, ошибки и очереди
(критерии и результаты: [docs/CORE_SOAK.md](docs/CORE_SOAK.md)); с `--real-modules telegram,voice,pet` то же с настоящими модулями в режиме
заглушек и убийством их процессов. Режим «только ядро»: настройка «Только ядро» в дашборде или `GITS_NO_MODULES=1`.

## Модули
Ядро принимает модули по WebSocket (`ws://127.0.0.1:8766/module/ws`, токен в `%LOCALAPPDATA%\GitS\module_token`) и само
запускает их по `agent/modules.yaml` (супервизор). Включаются и выключаются во вкладке «Модули» дашборда (там же настройки,
задачи и вопросы модулей). Профили поведения лежат в `agent/profiles/*.yaml`. Руководство автора модуля: [docs/MODULES.md](docs/MODULES.md),
ТЗ: [docs/tz/](docs/tz/README.md). Первый тестовый модуль, `echo` (`sdk/examples/echo_module.py`), выключен по умолчанию.

## Как проверять
```powershell
.\check.ps1       # ruff и все тесты: ядро, sdk, шаблон модуля, telegram, voice, pet, desktop, rimworld, montage
```
По частям (из корня репозитория):
```
python -m ruff check agent sdk services modules
python -m pytest -q agent/tests sdk/tests            # ядро и SDK
python -m pytest -q sdk/template/tests               # шаблон модуля
python -m pytest -q modules/telegram/tests           # то же для voice, pet, desktop; у каждого модуля отдельный запуск
```
Тесты не ходят в сеть, к микрофону, игре и Claude: модель и внешние службы заменены заглушками. Тесты `rimworld` и `montage` запускай
из их папок с `PYTHONPATH=sdk`. После правки контракта запусти `python sdk/tools/gen_contract_doc.py`, после правки схемы
`python -m tools.architecture.build` (из `agent/`).
