RimWorld: иерархия инструментов

Наведи на часть экрана игры, на узел дерева или на инструмент: связанные элементы подсветятся. Клик закрепляет выбор. Дерево и список инструментов строятся из манифеста модуля, снимки интерфейса сделаны в игре.

Интерфейс игры

Снимки сделаны из запущенной игры (docs/gui). Клик по вкладке на снимке переключает экран. Области заданы в UI_SCREENS генератора.

Порядок вызовов

where→open(path[, id])→действие узла→back
  • Навигация () работает всегда: open повторяет игрока (вкладка, категория Архитектора, выделение колониста), back поднимается на уровень выше, where показывает узел, его действия и дочерние узлы.
  • Действие узла работает только когда узел открыт. Вызов из другого узла отклоняется с подсказкой, какой узел открыть. В узле не больше действий.
  • Глобальные действия корня () доступны из любого узла, как кнопки внизу экрана.
  • Запросы (чтение, не меняют игру и не требуют открытого узла): дерево colony/*, map/*, work/*, pawn/* и т. д. Запросы панели узла подмешиваются в контекст при его открытии.
