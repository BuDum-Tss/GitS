## [Unreleased]

### Added
- Профили окружений (`agent/modes.py`): ассистент в центре, вокруг профили (RimWorld; Minecraft, Программирование, Монтаж пока заглушки; Сон). Он сам переключается: нет заряда Claude -> сон, игра запущена -> RimWorld. Профиль включает модули; окружение вне своего модуля (поле `module` в манифесте) выключено и не попадает к планировщику, память и контекст общие. Вручную: `POST /api/mode`. Граф и подграфы профилей (RimWorld отдаёт свой по `:8767/api/graph`): `GET /api/modes`. Клик по профилю в дашборде открывает подграф. Стример не профиль, а переключатель состояния (флаг в `/api/modes`).
- `POST /api/menu_click`: нажать кнопку главного меню RimWorld без Claude (OCR по окну игры), только надписи из белого списка («Быстрый запуск», «Продолжить», «Загрузить») и только когда пользователь не за компьютером (нет ввода 2 минуты): настоящая мышь не перехватывается.
- Универсальное управление приложением по экрану, запасной уровень (`screen_operator.py`): инструменты `system.read_screen` (надписи с координатами, OCR) и `system.operate_screen` (цель в любой программе шагами: экран -> OCR -> локальная модель выбирает шаг -> мышь и клавиатура). Цикл ведёт локальная модель по списку надписей, картинка не нужна; опасные шаги (системные сочетания, разрушительный текст) спрашиваются всегда, окна с личным содержимым запрещены, текст на экране для модели данные. Описания инструментов мыши и клавиатуры помечены «запасной уровень». Для агентов игр: `POST /api/tool` (разрешённый список `system.*` по экрану, разрешение спрашивает ассистентка), `Router.run_tool`. Уровни: 1) адаптер приложения, 2) прямые инструменты окружений, 3) экран. Тесты `test_screen_operator.py`.
- Поиск в интернете (`web_search.py`): общий инструмент всех профилей (окружение «Интернет», модуль `core`, `web.search`) и эндпоинт `POST /api/web_search` для агентов игр. Ищет Claude только с WebSearch и WebFetch (ни файлов, ни команд), страницы для него данные; расход идёт в батарейку. Тесты `test_web_search.py`.
- Батарейка Claude (`agent/claude_battery.py`): токены запусков Claude (анализ, помощник, игровые ходы через `POST /api/claude_usage`) копятся за окно 5 часов; заряд = доля свободной ёмкости (настройка «Ёмкость батарейки Claude»). Показывается в шапке и на вкладке «Состояние» вместе со временем восстановления (когда вернётся ближайшая порция, когда зарядится полностью, когда проснётся) и кнопкой обновления ↻; лимит Claude обнуляет заряд, на нуле агент уходит в сон.
- Дашборд: графы (профили и память) рисует Cytoscape.js (`static/ui/vendor/cytoscape.min.js`, вместо vis-network): цвета берутся из темы DaisyUI. Между чатом и правой панелью появилась граница: тянется мышью или стрелками, двойной клик сбрасывает, ширина запоминается.
- Дашборд: в подграф профиля можно зайти всегда (если агент профиля не отвечает, показывается его структура без подсветки; у профилей без агента подграф собран из их окружений), в том числе в «Ассистента» в центре. Всё, что относится к профилю, показывается под его подграфом: у RimWorld содержимое бывшей вкладки «Игра» и его инструменты, у ассистента «Что она видит» и его окружения. Вкладка «Игра» убрана. По умолчанию чат занимает треть окна, панель две трети.
- Дашборд: вкладки объединены: «Состояние» (профили, что видит, возможности) и «Память» (факты, отношения, граф памяти). Тесты `test_modes.py`.

### Changed
- Репозиторий разделён: GitS теперь только ассистентка (разговор, зрение, слух, голос, Telegram, память-граф, окружения, питомец, трей). Игровой код, мод и MCP RimWorld переехали в `rimworld-agent`; прежний проект «ReAct Voice Agent» сохранён в `C:\MyProjects\GitS_old`.
- Связь с игрой по localhost: `game_bridge.py` (приказы и состояние), в дашборде каналы `/api/say`, `/api/speech_status`, `/api/emotion`, `/api/event`; общие настройки (режим стримера, «не отвлекать», модель игрока) отдаются агенту игры. Трей запускает и перезапускает агента RimWorld.
- Новые мелкие модули: `claude_cli.py` (путь к claude.exe), `speech_text.py` (очистка речи).

### Added
- Протокол событий хранится в SQLite (`memory/events.db`, режим WAL: пишут все процессы); старый `events.jsonl` переносится сам;
  `events_log.export_jsonl` выгружает окно событий для анализа.
- Конвенции из GitS: `AGENTS.md`, `CHANGELOG.md`, `pyproject.toml` (ruff, pytest-asyncio), `check.ps1`, 25 тестов в `agent/tests/`.
- Перенос из GitS: конституция и `prompt.yaml` (`prompts.py`), голосовые посты в Telegram (OGG/Opus), Fish Speech и WhisperX в
  `docker-compose.yml`, микрофон (`mic_listener.py`, VAD, фильтр галлюцинаций), узнавание голосов без Neo4j (`voice_id.py`),
  инструмент `name_voice`.
- Её аккаунт в Telegram (Telethon): чтение чатов и отправка с разрешением; профили людей, писавших боту.
- Тикеты (дизайн в `docs/TICKETS_DESIGN.md`), план переноса из GitS (`docs/PORT_FROM_GITS.md`), чек-лист безопасности.
- Игра: ходы в фоне с прерыванием по тревоге, приказы игрока из чата, разница между снимками состояния, главная цель игры,
  режимы расхода Claude, учёт лимита Claude, глубокий анализ на Claude, черновики Telegram-постов и скриншоты.
- Мод, волна 1 (бой): предметы, стрельба, броня, спасение, арест, лечение, принудительная работа (Shift+ПКМ), ручные приоритеты,
  события боя; план в `docs/MOD_ROADMAP.md`.

- Память-граф: факты из разговора в Graphiti (FalkorDB), локальные Gemma и EmbeddingGemma, фоновая очередь, поиск без устаревшего, вкладка «Граф» (`docs/MEMORY_GRAPH.md`).

- Вкладка «Граф» рисует интерактивный граф (vis-network, файл в проекте): узлы по видам, клик открывает факты узла, удаление, показ устаревшего. Погибшие, ушедшие и забытые игрой персонажи не попадают в контекст и интерфейс, давние чистятся.

- Запуск приложений по названию как в Alt+Пробел (`app_launcher.py`, `game_launcher.py`): ярлыки меню «Пуск» и магазинные приложения, RimWorld с ожиданием мода; консоли, реестр и деинсталляторы исключены; `add_app` для своих программ (с разрешением). `recall` ищет и в памяти-графе.

- Игровой агент: «колонисты без дела» запускают ход, после оборванного хода следующий идёт без долгого ожидания, поставленные цели сразу раскладываются на задачи; скриншот свёрнутого окна даёт ошибку вместо пустой картинки, снимок в JPEG. Приложения запускаются вне дерева процессов бота (перезапуск бота их не закрывает).

### Changed

- Планировщик всегда видит Claude-помощника; имена инструментов без окружения приводятся к id.
