# Стикмен (пиктограмма из Portal)

`stickman_black.png` и `stickman_white.png`: силуэт человечка, указывающего рукой, с настоящей прозрачностью (в исходнике была нарисованная шахматка).
Присланы владельцем для повторного использования в роликах; использование разрешено владельцем (в регламенте «прав Valve» это исключение по его решению).
