# Поселенцы RimWorld (линии, прозрачный фон)

Белые линии на прозрачном фоне (PNG с альфа-каналом, высота 1000 px), нарисованы по портретам колонистов из записи эксперимента №1:
`noob.png` (длинные тёмные волосы, борода), `cervantes.png` (кудри, борода), `raido.png` (длинные волосы). Fugly добавить по тому же образцу.
Годятся для схем на синем фоне в клетку (чертёж): кладутся как есть, цвет не менять. Источник: присланы владельцем.
