Карточка этапа: объявление нового этапа (акта) ролика. Белый мир, слева крупный текст, справа готовая табличка камеры (`ChamberSign`).

**Порядок появления:** сначала печатается «Этап», небольшая пауза (`gap_ms`), затем название этапа (1-2 строки), и только потом справа выезжает баннер (`sign_at_ms`). Звучит только печать клавиатуры (`typing_src`); текст отбивки **не озвучивается**.

**Даёт монтажёр:** строки названия (`lines`: текст, размер, вес 300 или 700), номер и описание в баннере (`sign`: `big`, `small` без слова «Этап», `done`/`total`, `active`), дорожка печати.

- Без полоски над «Этап». Название в баннере не повторяется: `sign.title` = пробел.
- Размер строки подбирай так, чтобы она помещалась в левую колонку (до 840 px): жирная примерно 0,56 em на знак, тонкая 0,47. Иначе текст залезет на баннер.
- Каждый этап ролика объявляется этой карточкой, в одном стиле.
- Файлы: `StageCard.tsx` (компонент, регистрируется как `TitleSplit` в `work/src/custom/index.ts`), `lab.tsx` (общие помощники: печать, курсор, `TypeSound`), `typing_sound.py` (синтез дорожки печати), `example.json` (вставка для `plan.json`), `preview.png`.
- Курсор оранжевый стоит на базовой линии строки.
