Серая рамка в стиле заставки Aperture Laboratories для наложения на футажи: прозрачный фон, замкнутая тонкая линия по периметру, плотные сегменты, угловые скобы и тики. Горизонталь 1920×1080.

**Даёт монтажёр:** ничего, рамка фиксированная; кладётся поверх записи игры или комнаты. Текста в рамке нет.

- Файл: `frame-horizontal.svg` (viewBox 1920×1080, заливка `#6b6f75`, непрозрачность 30 %, фон прозрачный).
- Рамка вплотную к краю кадра (без отступа), полупрозрачная (30 %), до 16 px вглубь, центр не закрывает.
- Эта же рамка стоит в заставке `Intro`. Для вертикального ролика есть своя `FrameVertical`.
