Схема-чертёж объясняет устройство: план комнаты, колонии, механизма — синий лист в клетку со светом из центра, белые линии рисуются, подписи выносками.

**Даёт монтажёр:** что изображено (модель описывает, агент рисует SVG-линиями из простых фигур), подписи-выноски (до 4, каждая до 40 символов), название и рубрика для таблички.

- Фон: радиальный градиент `bp-center` → `bp-mid` → `bp-edge` (свет из центра) и две сетки: `bp-grid` с шагом `bp-cell`, `bp-grid-major` с шагом `bp-cell-major`; рамка листа в 28 px от края.
- Линии `bp-line`: контур 3 px, вспомогательные 1,6 px, стены 10 px; концы и углы скруглены.
- Анимация `bp-draw`: линии прорисовываются, затем появляются подписи.
- Табличка слева внизу: `bp-title` (наклон 8°), мелкая строка и рубрика `bp-kicker`; мелкий текст справа `bp-fine` — только декоративный.
- Не делать: заливки, тени, цветные линии; больше 4 выносок.
