Иконки табличек: залитые скруглённые силуэты в квадратах — колонисты, стройка, сон, исследования, пожар, набег, потери, животные, холод, ночь, здоровье, куб, кнопка, подопытный, aperture (ирис из восьми лопастей, он же знак интро).

- Рисуются встроенным SVG цветом `currentColor`: активные `sign-ink`, неактивные `sign-off`; детали-вырезы цветом фона (`--icon-bg`).
- Квадрат `sign-box` (104 px, рамка 4 px), иконка 76 px.
- Новые иконки — тем же языком: один залитый силуэт, скругления, без тонких контуров; свои рисунки, не копии табличек из игр Valve.
