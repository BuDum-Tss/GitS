Заставка открывает каждый ролик: Aperture Boot Sequence, 60 к/с, 7,1 с, со звуком из ролика-референса «Aperture Science theme». Четыре готовых видеофайла (mp4, h264 + aac) лежат в ассетах, группа «Intro»:

| компонент | файл | размер кадра | вид |
|---|---|---|---|
| `Intro` | `Aperture_Boot_dark.mp4` | 1280×720 | белый знак на чёрном |
| `IntroLight` | `Aperture_Boot_light.mp4` | 1280×720 | чёрный знак на белом |
| `IntroVertical` | `Aperture_Boot_vertical_dark.mp4` | 1080×1920 | белый знак на чёрном, своя вертикальная рамка |
| `IntroVerticalLight` | `Aperture_Boot_vertical_light.mp4` | 1080×1920 | чёрный знак на белом, своя вертикальная рамка |

В превью компонента играет это видео; если оно не загрузилось, на его месте та же анимация, нарисованная векторами (она же лежит в основе роликов-сборок).

**Даёт монтажёр:** ничего, надпись и знак фиксированные (это не слова модели).

Тайминг (снят покадрово с референса):
- 0–1,05 с: чёрный экран, без элементов.
- 1,05–1,5 с: справа (x 1131, y 350) появляется иконка-ирис (иконка `aperture` из набора «Иконки»), растёт до диаметра 204 px, вращаясь; поверх надписи в режиме `difference`.
- 1,5–2,2 с: ирис катится влево без проскальзывания, с горизонтальным смазом по скорости; за ним справа налево открывается `APERTURE`. Ирис останавливается на x 282.
- 2,2–2,6 с: `LABORATORIES` проявляется из тёмного и поднимается на 180 px по кривой с замедлением, размытие снимается.
- 2,6–7,1 с: неподвижный логотип; по периметру полупрозрачная (30 %) замкнутая рамка вплотную к краю.
- Финала в «круговой индикатор» в референсе нет: ролик заканчивается неподвижным логотипом.

Знак и буквы — контуры, снятые с кадра референса (не шрифт), поэтому не деформируются. Движение: ease-out и линейные участки, без отскоков.
Права: знак и название Aperture Laboratories — собственность Valve; для публичных роликов это решение владельца.
