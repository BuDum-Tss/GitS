# Память-граф

Факты о людях и жизни из разговора хранятся в графе Graphiti (база FalkorDB), всё локально: извлечение делает Gemma,
эмбеддинги EmbeddingGemma-300M, оба в LM Studio. Код: `agent/graph_memory.py`. Решение принято по результатам пробы (ниже).

## Как устроено
1. Реплика человека (чат, голос с подписью, Telegram-бот) попадает в очередь `memory/graph_queue.json` (переживает перезапуск).
   Короче 12 символов не берём; реплики ГЛаДОС не берём; незнакомые голоса не запоминаем.
2. Когда разговор не идёт (20 секунд тишины и она не говорит), Gemma одним запросом со строгой схемой выписывает устойчивые
   факты (кто, связь, что, фраза). Просьбы и мелочь дают пустой список.
3. Каждый факт пишется в Graphiti через `add_triplet`: он сливает дубли сущностей, закрывает устаревшие факты датой
   («живёт в Москве» закрывается, когда появляется «живёт в Казани»), считает эмбеддинги.
4. Поиск: перед ответом по теме реплики берутся факты (не дольше 3 секунд), устаревшие не показываются, слабые совпадения
   отсекаются порогом косинуса 0,5. Блок попадает в контекст разговора.
5. Вкладка «Граф» в дашборде: действующие и устаревшие факты, удаление кнопкой ✕. Настройка «Память-граф» включает и выключает.
Если база, LM Studio или модели недоступны, граф отключается сам, очередь копится, бот работает как раньше.

## Колонисты из игры
Данные о действующих колонистах берутся из состояния игры (не из разговора) и ПЕРЕЗАПИСЫВАЮТСЯ: каждый колонист это узел, связанный с узлом-поселением (отношение КОЛОНИСТ), плюс по одному факту на навыки, черты и состояние; сама ГЛаДОС связана с поселением отношением УПРАВЛЯЕТ, у поселения есть факт СОСТАВ. Изменившийся факт заменяет прежний (без участия модели, быстро); неизменившиеся не пишутся; колонист, которого больше нет, закрывается датой и в поиске не показывается. Синхронизация идёт при смене состава и раз в пять минут.

## Эксплуатация
- База: `docker compose up -d graph` (контейнер `glados-graph`, порт 6380, ~70 МБ). Версия образа закреплена на `v4.22.0`:
  свежий `latest` (6.x) несовместим с текущим Graphiti.
- Модели LM Studio загружаются сами через `lms load` (подгрузка по запросу отменяет загрузку второй модели).
- Телеметрия Graphiti выключена (`GRAPHITI_TELEMETRY_ENABLED=false`).
- Установка: `pip install graphiti-core[falkordb]`.

## Почему извлечение наше, а не Graphiti
Проба на 10 репликах. Полный конвейер Graphiti на Gemma 4B (4 прогона): принимает без сбоев, но теряет половину фактов
(не нашёл ни переезда, ни кота), по 80-130 секунд на реплику. Та же Gemma одной простой задачей «выпиши факты»: все факты,
4-23 секунды. Запись готовых фактов в Graphiti: 8 фактов за 85 секунд, замена «Москва → Казань» сработала, поиск по смыслу
на русском работает.

## Известные ограничения
- Объект «работает удалённо» вместо «работает дизайнером удалённо» может ошибочно закрыть прежний факт о работе (подправлено промптом).
- Старая память (`memory_store`) осталась как была: планы с датами и напоминания там, граф только для знаний. При первом
  запуске старые факты о пользователе перенесены в очередь; почти все оказались неудачными заметками и фактов не дали.
- Скорость: ~15-30 секунд на реплику в фоне; при активном разговоре очередь копится и догоняется в паузах.
