# 23. Сцены дизайн-системы в шаблоне Remotion

Этап 4, после шага 2 монтажёра (ТЗ 20). Репозиторий: `montage-module`. Ветка: `tz/23-design-scenes` от `master`.
Источник правды по виду: дизайн-система «Лаборатория Aperture», версия 2 (https://claude.ai/artifact/8qEnTgL2fffuV9NybZ9Fj2).
Её файлы лежат локально в папке, которую назовёт планировщик (`project/README.md`, `project/tokens.json`,
`project/components/bundle.css`, `project/components/<Сцена>/preview.html` и `README.md`).

## 1. Решение владельца (2026-10-11)

Ролик собирается из пяти сцен, и у каждой элемента должна быть причина:

1. **Интро** — заставка с ирисом и надписью, 4 с.
2. **Схемы** — чертёж-blueprint: синий лист в клетку со светом из центра, белые линии рисуются, выноски, табличка.
3. **Комната ГЛаДОС** — фон комнаты и крупный питомец по центру с анимацией покоя и речи, без облачков текста.
4. **Субтитры** — только в вертикальных роликах. В горизонтальных выдаётся `.srt`.
5. **Отбивки** — таблички тестовой камеры на белом: акт (`chamber_sign`) и итог (`result_sign`).

Плюс рамка HUD поверх игры (`footage_frame`) и новые залитые иконки в квадратах. Из стиля убираются угловатые
пиктограммы, баннер опасности, панель итога и красный «тревожный» цвет.

## 2. Требования

- **SC-1 (ОБЯЗАТЕЛЬНО).** `template/src/style/tokens.ts` приводится к `tokens.json` дизайн-системы v2. Цвета: sign-*,
  bp-*, chamberDark, chamberDark-plate, labWhite, labGrey, portalBlue, portalOrange. Типографика, размеры и
  длительности — тоже оттуда. Цвета, которые убраны (hazardYellow, alertRed), из стиля удаляются. Компоненты, которые
  на них опирались, удаляются или переделываются по SC-2.
- **SC-2 (ОБЯЗАТЕЛЬНО).** Новые компоненты в `template/src/components/`. Внешний вид — пиксель в пиксель с превью
  дизайн-системы: размеры, отступы, шрифты и тайминги из `bundle.css` и README сцены. CSS-анимации превью
  переводятся в покадровую анимацию Remotion (`interpolate`/`spring` без отскока; ease-out для входа).
  - `Intro`: props `subtitle` (≤ 60), `wordmark` (по умолчанию `APERTURE SCIENCE`). Ирис из 8 лопастей — геометрия как
    в превью: лопасти `[R(150,a), R(150,a+45), r(52,a+45+24), r(52,a+24)]`.
  - `Blueprint`: props `title`, `kicker`, `note`, `callouts[]` (`{x, y, label}` — доли кадра, до 4), `drawing` (список
    SVG-примитивов `line|rect|circle|path` в долях кадра; рисует агент). Линии прорисовываются за `bp-draw`, подписи
    появляются после.
  - `GladosRoom`: props `moods[]` (`{from_ms, to_ms, mood}`), речь из `voiceover` и журнала речи. Фон —
    `public/scenes/glados-room.webp`, питомец — `public/pet/<mood>.png`. Покой `pet-bob`; во время речи масштаб по
    громкости голоса (`@remotion/media-utils` `visualizeAudio` или амплитуда WAV), до 1,025. Смена эмоции — кроссфейд
    150 мс со сжатием 0,96 → 1. Высота питомца 62 % (горизонталь) или 42 % (вертикаль).
  - `ChamberSign` и `ResultSign`: props `big`, `small`, `done`, `total`, `active[]` (иконки), `title`. Выезд снизу
    300 мс, держится `bumper-hold`, уход к белому.
  - `FootageFrame`: оверлей `public/hud/hud-frame.svg` поверх сегментов игры и подпись `hud-label`.
  - `Icon`: 14 иконок из превью `Icons` (SVG-пути один в один), `currentColor`.
- **SC-3 (ОБЯЗАТЕЛЬНО).** Схема плана (`schema.ts` → `plan.schema.json`): вставки `intro`, `blueprint`, `glados_room`,
  `chamber_sign`, `result_sign`. У сегментов флаг `frame: "hud"`. Старые kind (`chamber_card`, `hazard_banner`,
  `test_result`, `pixel_transition`, `lower_third`) удаляются. `plan_schema.py` и проверки монтажёра обновляются через
  `plan.schema.json` (единый источник).
- **SC-4 (ОБЯЗАТЕЛЬНО).** Субтитры рисуются только при вертикальном формате. При горизонтальном и квадратном — не
  рисуются, а финальный рендер кладёт рядом `.srt` с теми же словами (страницы по `combineTokensWithinMilliseconds`).
- **SC-5 (ОБЯЗАТЕЛЬНО).** Ассеты в `template/public/`: фон комнаты, 6 эмоций питомца, рамка HUD — копии из мест, которые
  назовёт планировщик. Если питомца в высоком разрешении нет — текущие стикеры, а в README пометка «нужна версия от
  1000 px».
- **SC-6 (ОБЯЗАТЕЛЬНО).** Регламент `docs/APERTURE_STYLE.md` переписан под пять сцен (как README дизайн-системы v2);
  `editor_system.md` монтажёра знает сцены, когда какую ставить и правило «субтитры только в вертикали»; рубрика QA —
  тоже.
- **SC-7 (ОБЯЗАТЕЛЬНО).** Демо-планы: шортс (интро → комната → схема → игра с субтитрами → итог) и YouTube (интро →
  отбивка → комната → схема → игра в рамке → итог). `remotion still` ключевых кадров каждой сцены и сравнение с превью
  дизайн-системы глазами (Read обеих картинок). Расхождения — в отчёт.
- **Проверки:** `check.ps1` зелёный (tsc, compositions, pytest); коммиты на английском с `Co-Authored-By`; без push.
