## 1. Что нашлось в живом прогоне (2026-10-11, забег 00:09–05:33)

- Видео (`raw_000912.mp4`) записалось целиком: 5 ч 25 мин (19 479 с), 296 МБ.
- **Звук оборвался через 2 ч 59 мин** (`raw_000912.wav`: 10 781 с, 1,90 ГБ, файл перестал расти в 03:08). Причина
  не установлена. Вероятно, предел размера WAV или ошибка потока записи `audio_capture.LoopbackRecorder`. Проверь журнал
  и код, найди причину до исправления и опиши её в отчёте.
- **Нарезка по сценам на длинной записи очень медленная:** `montage_args`/`clip_args` вырезают сцены фильтром `trim`
  из одного входа, поэтому ffmpeg декодирует видео с начала для каждой сцены. На 5-часовой записи монтаж не завершился за
  разумное время (прерван вручную).
- `_with_audio` склеивает звук с `-shortest`: если звук короче видео, обрезается и видео.

## 2. Требования

- **REC-1 (ОБЯЗАТЕЛЬНО).** Звук пишется без ограничения длины забега. Варианты (выбрать по найденной причине, описать):
  запись кусками по 30 минут (`raw_HHMMSS_aNN.wav`) с точным временем начала каждого куска, или запись через ffmpeg в
  формат без предела 4 ГБ (`-rf64 auto` / сразу в AAC/FLAC). Склейка кусков — по времени начала. Тест на синтетическом
  потоке: 3 куска, правильные смещения.
- **REC-2 (ОБЯЗАТЕЛЬНО).** Сбой записи звука посреди забега не молчит: событие `video` в журнал и попытка перезапуска
  записи звука (новый кусок), как `ensure_alive` для видео.
- **REC-3 (ОБЯЗАТЕЛЬНО).** Нарезка с перемоткой: каждая сцена — отдельный вход `-ss <start> -to <end> -i raw`
  (быстрая перемотка до ближайшего ключевого кадра + точная доводка), затем `concat`. Для клипов — так же. Проверка:
  монтаж 5 сцен из 5-часового синтетического файла (ffmpeg `testsrc`, низкое разрешение, генерируется в тесте или
  разово скриптом) укладывается в 2 минуты; результат совпадает по длительности со старым способом ± 0,2 с.
- **REC-4 (ОБЯЗАТЕЛЬНО).** `_with_audio` без `-shortest`: видео не обрезается по звуку; если звука меньше — тишина
  (`apad`) до конца видео.
- **REC-5 (ОБЯЗАТЕЛЬНО).** Скрипт `agent/tools/produce_run.py <папка_забега> [--raw raw_X.mp4]`: смонтировать уже
  записанный забег тем же кодом (`RunRecorder.process`). Нужен для забегов, остановленных вручную, и для повторной
  сборки после правки сценария. Время начала — из имени файла и метаданных; события — из `events_log` за окно записи.
- **REC-6 (ЖЕЛАТЕЛЬНО).** Ограничение размера: при `record_runs` и забеге длиннее `max_record_hours` (настройка модуля, по
  умолчанию 6) запись переходит в следующий кусок видео (как `ensure_alive`), чтобы файлы не росли бесконечно.
