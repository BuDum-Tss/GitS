# Память персонажа

Вся память это эпизоды: короткие тексты от первого лица, в которых уже есть что произошло, на что она обратила внимание и как к этому относится.
Отдельных полей «отношение», «факты», «эмоции» и отдельного профиля владельца нет. Хранилище `episodes.db` в папке памяти персонажа
(`agent/services/memory_service/episode_store.py`), поиск общий (`search/`: FTS5 по словам и векторы EmbeddingGemma; без LM Studio поиск идёт по словам),
индексируется `заголовок. текст` целиком.

## Виды эпизодов (`kind`)
- `life`: события из журнала. Яркий момент пишет форк её сессии (`episode_fork.py`) или запасной писатель (`episode_summary.py`); она вправе ничего не писать.
  Форк просит текст, где названы имена, места, предметы и ключевые слова события, чтобы запрос по слову находил эпизод.
- `canon`: воспоминания персонажа о себе из `core/memories.yaml` (`mem_id`, `mtype`, `weight`). Загрузка идемпотентна и идёт сама при открытии памяти
  (`character_seed.seed_canon`); обновление по `mem_id`. Канон защищён: его не стирает «забудь» и не перезаписывает «запомни», меняет только yaml.
- `note`: записи «запомни» (важность 3-5, мелочь не пишется), договорённости, поправки; сюда же перенесены факты старого графа. Яркость заметки это важность / 5.

## Контекст ответа (`episode_memory.py`)
- «Твои воспоминания (это о тебе)»: канон, подходящий к реплике, до трёх. Оценка: косинус по векторам индекса плюс прибавка за общие слова;
  без эмбеддера или у записи без вектора только общие слова (`character_memory.word_scores`: «помнишь Кэролайн?» находит запись с этим именем). Если ничего не подошло,
  раз в пять реплик напоминание о привычке или мнении.
- «Что ты помнишь по теме»: остальные эпизоды (жизнь и заметки) тем же гибридным поиском, до четырёх; свежесть и яркость идут в вес.
- Записи о владельце ничем не выделены: это обычные эпизоды.

## Запись и забывание
`UserMemoryAdapter.add_fact`: user, self и episode превращаются в заметку, plan в задачу. Инструменты `recall`, `remember`, `forget`, `recall_episode` и запросы пиров
`core.memory.recall` и `core.memory.remember` работают на эпизодах. Забывание трогает жизнь и заметки, но не канон.

## Перенос старого графа
При открытии памяти персонажа `graph_import.migrate_graph` один раз (отметка `migrated_graph` в `meta`) переносит действующие факты из `graph.db`: воспоминания
персонажа (`canon=1`, `mem_id`) в канон, остальное в заметки (в тексте есть имя субъекта); состояние колонистов не переносится. Файл переименовывается в
`graph.db.migrated`, не удаляется. Сначала переносится граф, потом загружается канон из yaml.

## Состояние колонии
Данные RimWorld о колонистах это состояние мира, не память: `services/event_handlers/colony_state.py` (`colony_state.json`), по теме реплики блок «Состояние игры».
